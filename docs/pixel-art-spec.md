# Xiangyu's AI Lab — Pixel Art Specification v0.3

最后更新：2026-07-29

本文档是 v0.3 正式美术与地图管线的生产基准。玩家、家具、站点、地图和碰撞数据都应遵守同一套逻辑尺寸；如需调整，先更新本文档，再批量生产素材。

## 1. Canvas and Grid

| 项目 | 规范 |
|---|---|
| 逻辑分辨率 | 960 × 540 px |
| 基础网格 | 16 × 16 logical px |
| 半格单位 | 8 px，只用于角色、细节和碰撞微调 |
| 地图坐标 | 整数 logical px，主要家具的占地与锚点优先对齐 16 px 网格 |
| 运行时采样 | Nearest-neighbor；禁止单个 sprite 的平滑缩放 |
| 视口适配 | 整体 Canvas 使用 `FIT`；素材保持 1× 逻辑像素，CSS 使用 `image-rendering: pixelated` |

所有正式素材以 1× logical pixel 导出。可以放大预览，但源文件禁止使用双线性缩放、抗锯齿、模糊和半透明外发光模拟像素边缘。

## 2. Player Standard

| 项目 | 规范 |
|---|---|
| 单帧尺寸 | 40 × 48 px |
| Sprite sheet | 2 列 × 4 行，共 80 × 192 px |
| 行顺序 | down、left、right、up |
| 列顺序 | idle、walk |
| 角色可见范围 | 建议不超过 36 × 46 px |
| 脚底基线 | 每帧 y = 45 px 附近，所有方向保持一致 |
| 物理碰撞体 | 16 × 14 px，位于角色下半身脚部区域 |
| 阴影 | 20 × 7 px，运行时绘制，不烘焙进 sprite |

角色识别要点：黑色短发、黑框眼镜、深色工程夹克、浅色内搭、深色长裤、浅色鞋；青色和紫色只作为很小的系统光细节。轮廓优先于服装纹理，40 × 48 px 下必须能区分脸朝向和步态。

## 3. Furniture and Stations

- 小型道具：1 × 1 至 2 × 2 tiles。
- 桌面、终端和档案柜：以 2 × 2、3 × 2、4 × 2 tiles 为常用占地。
- 核心装置：允许使用 8 px 半格偏移，但碰撞边界仍使用整数像素。
- 视觉轮廓可以超出占地；碰撞体只覆盖落地部分，并允许角色在前景装饰下方行走。
- 交互范围独立于碰撞体，默认在落地边界外扩 24–32 px。
- 正式素材替换后，五个 `StationId`、React 面板和访问状态协议保持不变。

### Living AI Core v1

| 项目 | 规范 |
|---|---|
| 运行时纹理 | 192 × 160 px |
| 可见主体 | 约 153 × 154 px |
| 场景视觉范围 | 176 × 144 px |
| 纹理原点 | x = 0.5、y = 0.62 |
| 底座碰撞 | 128 × 56 px，相对站点中心向下偏移 36 px |
| 深度规则 | Core 深度使用站点 y；玩家深度使用实时 y，实现前后遮挡 |

Core 的玻璃、知识树和发光节点烘焙在同一张不透明像素素材中；运行时只增加低强度 aura，不用大面积模糊光效覆盖像素轮廓。

### Experience Archive v1

| 项目 | 规范 |
|---|---|
| 运行时纹理 | 192 × 128 px |
| 可见主体 | 约 176 × 105 px |
| 场景视觉范围 | 176 × 128 px |
| 纹理原点 | x = 0.5、y = 0.62 |
| 落地碰撞 | 160 × 48 px，相对站点中心向下偏移 32 px |

Archive 左侧使用琥珀 / 朱红表现经历与生活记忆，右侧使用深海军蓝、金色与青色表现当前研究工作。企鹅玩偶是原创的黑白纪念物，不复刻腾讯或 QQ 官方形象；HKUST / HKGAI 背景通过研究笔记、证件和配色暗示，不使用校徽或机构 Logo。

## 4. Tiled Object Contract

- 生产地图：`public/assets/game/maps/lab-v1.tmj`。
- Tile size 固定为 16 × 16 px，地图属性 `schemaVersion` 固定为 `1`。
- `World` 对象层保存世界边界和玩家出生点。
- `Collision` 对象层保存静态障碍物和五个站点的落地碰撞。
- `Stations` 对象层保存五个站点的视觉范围、交互外扩、状态色和可选标签间距。
- Tiled 矩形使用左上角坐标；运行时解析器统一转换为 Phaser 中心坐标。
- 完整字段和编辑规则见 [`tiled-map-schema.md`](./tiled-map-schema.md)。

### Room Base Tileset v1

| 项目 | 规范 |
|---|---|
| 运行时纹理 | 256 × 256 px，RGBA |
| Tile grid | 16 列 × 16 行，共 256 tiles |
| 单 tile | 16 × 16 px |
| 模块单位 | 4 × 4 tiles，即 64 × 64 px 面板概念 |
| 生产图层 | `Floor`、`Structure` |
| 采样 | Phaser `NEAREST`；Tiled 图层不得平滑缩放 |

tileset 采用“64 px 视觉模块 / 16 px 编辑单元”：模型生成的完整面板不直接压缩成单 tile，而是拆分为 4 × 4 tile 组合，避免重复纹理过密。青色导管和紫色节点保持稀疏，地板图层使用低透明度，不与人物、站点和香港窗景争夺注意力。

## 6. Export and Naming

- PNG、RGBA、透明背景。
- 文件名使用 kebab-case，并带主体和版本，例如 `xiangyu-player-v1.png`。
- 地图引用路径以 `/assets/game/` 为根，避免构建时 hash 改写地图内部 URL。
- 原始生成图保留在 `design/sources/`，避免被生产构建复制；运行时整理后的 spritesheet 放在 `public/assets/game/sprites/`。
- 禁止在 sprite sheet 中保留文字、帧编号、网格线、水印或接触阴影。
- 每项正式素材必须登记生成方式、人工处理和使用状态。
